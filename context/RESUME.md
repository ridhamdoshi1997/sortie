### Real bugs caught live this phase (each fixed same-session, not left open)

- **`posted_at` frozen-text bug**: `job.posted_at` is Google Jobs' own relative string ("2 days ago") captured once at scrape time, never refreshed — a job found weeks ago would permanently show "Posted 2 days ago." This also silently broke `isStaleByAge` (`new Date("2 days ago")` = Invalid Date, no-op'd for any job with `posted_at` set). Fixed: `isStaleByAge` only reads `found_at` now; the badge shows a real computed `Found {formatTimeAgo(foundAt)}`.
- **Native `<select>` unreadable in dark mode**: Theme/Page size dropdowns' OS-chrome popup rendered every non-selected `<option>` in washed-out grey, unrelated to this app's CSS. Replaced with a custom `Dropdown` component.
- **That fix's own popup then invisible**: it lived inside `Group`'s `overflow-hidden` accordion wrapper, which silently clipped the absolutely-positioned popup. Fixed by portaling to `document.body` with `position:fixed` computed from the trigger's real `getBoundingClientRect()` — the exact pattern already proven in `ResumeManager.tsx`'s row-action menu.
- **That portal fix then "floated" disconnected on scroll**: `position:fixed` doesn't track the trigger when the side panel's own `overflow-y-auto` scrolls. Fixed by closing the panel on any scroll (`capture:true` on `window`, catches the nested scroll container too).
- **"Click the title to edit" was undiscoverable**: tried twice — first the whole title became a `Link` (only accent-colored on `:hover`, read as plain text at rest); reverted to a plain heading + explicit "Edit"/"View" text links, which then read as unfinished next to a solid button; researched via `agy` and landed on primary(solid)+secondary(outline) button hierarchy — `Edit`/`View` are now real outline buttons.
- **Browser-native `window.confirm`/`window.alert`**: user-flagged as unprofessional. New reusable `components/ui/ConfirmDialog.tsx` (same glass-modal chrome as `SectionModal.tsx`) replaces it everywhere it was used (`ApplicationDocumentsCard.tsx`, `ResumeManager.tsx`, `ResumeAnalysisView.tsx`).
