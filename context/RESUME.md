- **New in Phase 8:** Next.js 16's dev server now refuses to start a second genuinely-independent instance while another one is already running against the same project directory — a fresh `next dev -p <other-port>` prints "✓ Ready" and then immediately "⨯ Another next dev server is already running" (naming the first instance's PID) and never actually binds/serves (confirmed via `curl` returning connection-refused on the new port).
